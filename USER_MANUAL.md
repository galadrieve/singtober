# User Manual

This repository is the home of a writing project, powered by
[daily-writing](https://github.com/ewjoachim/daily-writing).

## How to deploy

<!-- BEGIN pages -->
⚠️ GitHub Pages is not enabled yet, so your site won't deploy. Turn it on in [Pages settings](../../settings/pages) by setting the source to **GitHub Actions**.

- In [Pages settings](../../settings/pages), under Source, use GitHub Action. (It's always a good idea to ensure HTTPS is checked).
- You may need to commit for this to take effect, so maybe take this opportunity to update the content of this [README](../../edit/main/README.md) which powers the homepage of your site
- A few seconds after committing, your website should be deployed at {github_pages_url} and at your custom domain if you have configured one.

### How to use a custom domain

See [Github's doc](https://docs.github.com/en/pages/configuring-a-custom-domain-for-your-github-pages-site)

## Publishing schedule

Your site rebuilds every day just after midnight so the day's writing goes live on
time. GitHub Actions cron schedules run in UTC and must be a fixed literal value,
so the exact schedule for your configured `timezone` is computed for you below.
Applying it is a manual step: GitHub heavily restricts edits overs
workflow files.

Edit [`.github/workflows/publish.yml`](../../edit/main/.github/workflows/publish.yml)
and replace its `schedule:` section with the following. This block is kept up to
date for you automatically — re-copy it whenever you change your timezone in
[`daily-writing.toml`](/daily-writing.toml).

<!-- BEGIN cron -->
```yaml
  schedule:
  - cron: '1 22 * * *'
  - cron: '1 23 * * *'
```
<!-- END cron -->

## Autofix.ci

We're using, [autofix.ci](https://autofix.ci) to help your project stay in good shape. autofix.ci is what commits those results back to the pull request. Without it installed, those updates are still computed in CI but never saved, so they never reach your repository.

To enable it, install its app on this repository: [activate autofix.ci](https://github.com/apps/autofix-ci/installations/new) and, when prompted, grant it access to this repo.

## How to configure, how to add writings

Please refer to the [`daily-writing` doc](https://github.com/ewjoachim/daily-writing) for configuration details and how to add new writing so that they appear properly.

### Using the web interface

Once your website is deployed, head to {github_pages_url}/admin, log in using a token as
instructed, then edit your website's settings, and add writings. While optional, you can
improve the authentication setup if you want, see the [`daily-writing` doc](https://github.com/ewjoachim/daily-writing#online-with-sveltia)


### Editing your website manually

Your website is entirely generated by the files here:
- [`daily-writing.toml`](/daily-writing.toml) for the configuration
- [`README.md`](/README.md) for the homepage
- Markdown files under `<year>/<month>` for your writings.

Editing those files through `git` or through the GitHub interface should work too.

### Favicon

One way of generating a nice favicon is by using favicon.io .
Once you get the favicon files, upload them to the [`static`](/static) folder of the repo and commit.

Update the relevant parts of [`daily-writing.toml`](/daily-writing.toml) (look for `icon-links`).

If you've used favicon.io, chances are you won't even have to change a thing, just upload your own files in place of the default ones.
