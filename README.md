# Singtober

Vous connaissez Inktober ? Bienvenue dans Singtober.
En partant des mêmes prompts, on est partis pour un mois de petits extraits de chanson qui contiennent le prompt.
On s'ajoute un petit défi : pas plus de 30 min pour enregistrer un morceau.
Par contre, ça sera très probablement du #NoFilter 😅
